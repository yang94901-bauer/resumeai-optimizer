# ATS-Friendly English Resume Template

Use this template to build a resume that passes Applicant Tracking Systems (ATS) and impresses Western hiring managers.

## Formatting Rules
- Single column layout (ATS cannot parse multi-column tables)
- Standard section headers: Professional Summary, Experience, Education, Skills, Certifications
- Use .docx or PDF format
- Font: Arial, Calibri, or Helvetica, 10-12pt
- 1-2 pages maximum
- No photos, no age, no marital status, no nationality
- Save as: FirstName_LastName_Resume.docx

## Action Verbs Cheat Sheet
Leadership: Led, Directed, Managed, Spearheaded, Orchestrated
Achievement: Delivered, Achieved, Exceeded, Generated, Secured
Development: Developed, Built, Designed, Engineered, Implemented
Improvement: Improved, Optimized, Streamlined, Enhanced, Accelerated
Analysis: Analyzed, Evaluated, Assessed, Forecasted, Researched
Collaboration: Collaborated, Partnered, Coordinated, Facilitated, Negotiated

## Common Mistakes to Avoid
- Using "responsible for" (passive) → use action verbs
- Listing duties instead of achievements → quantify everything
- Including personal info (photo, age, marital status)
- Using columns/tables that break ATS parsing
- Inconsistent dates or formats
- Typos in headers (ATS matches exact keywords)
